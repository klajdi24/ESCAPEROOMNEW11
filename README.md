# Pirate Escape Room VR Project

## Description
This is my Pirate Escape Room VR project built in Unity using the XR Interaction Toolkit.  
The project allows players to interact with objects in a VR environment to solve puzzles and escape the room.

## Instructions

### Running in Unity Editor
1. Open the project in Unity (Unity 2021.3 or newer recommended).  
2. Open the main scene (e.g., `EscapeRoomScene`).  
3. Press **Play** in the editor to test VR interactions.  

### Building for VR
1. Before building the project for VR, **disable the XR Device Simulator** in the Hierarchy.  
   - This is important because the XR Device Simulator causes issues when building the project.  
2. Go to **File → Build Settings → Build** and select your target platform (Windows/Mac).  
3. Build and run the standalone executable.  

## Controls
- Use your VR controllers to grab, move, and interact with objects in the escape room.  
- Solve puzzles.
